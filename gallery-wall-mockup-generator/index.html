What a set mockup has to prove

A buyer looking at a set of 3 is asking one question: will these look right together in my home? Your photo answers it when four things are true.

  • The pieces share one size and one frame colour
  • The gaps between them are equal
  • They share a centre line, not a top or bottom edge only
  • The group fits the furniture below it, with wall to spare

Choose the room by the group's total width, not the size of one piece. A trio needs a wide wall; a pair of tall portraits can fill a narrow pier between doors that would swamp a single large print. Our guide to pair and trio mockups has more on matching rooms to sets.

Gallery wall spacing, worked through

Total width of a row = (frame width x number of pieces) + (gap x number of gaps). There is always one gap fewer than pieces.

  • Three 16 x 20 inch frames, hung portrait, 3 inch gaps: 16 x 3 + 3 x 2 = 54 inches wide.
  • Two 24 x 36 inch frames, hung portrait, 3 inch gap: 24 x 2 + 3 = 51 inches wide.
  • Four 12 x 12 inch frames in a 2 x 2 grid, 3 inch gaps: 12 x 2 + 3 = 27 inches square.

Use the gallery wall spacing calculator for your own sizes, and the art size over a sofa tool to check the group fits the furniture. Put these totals in your listing too: buyers with a set in their basket want to know if it fits their wall.

Questions

How many pieces can a WallMock gallery wall mockup show?

Sets of 2, 3 or 4 pieces on one wall: pairs, trios and sets of four. For a larger salon-style wall, plan it with the free gallery wall layout planner.

How far apart should pieces in a set hang?

Even gaps of about 3 to 6 inches (8 to 15 cm) look tidy for most sets. Smaller pieces can sit closer; very large canvases can sit a little further apart. The gallery wall spacing calculator does the sums.

What is the difference between a triptych and a set of 3?

A triptych is one image split across three panels, so the panels only make sense together. A set of 3 is three separate artworks that share a theme, colour or style. Both are shown as three matching frames in a row.

Can I mock up a gallery wall with different sizes?

WallMock sets are made for matching pieces. For mixed sizes, use the layout planner to plan the arrangement, then show each piece on its own in a room.

Should every piece in a set use the same frame?

For a set you sell together, yes. One frame colour and one size makes the group read as a single piece. Mixed frames suit eclectic gallery walls, which are harder to sell as one product.

Will each artwork in the set stay exact?

WallMock places your file as it is: it is never redrawn, repainted or upscaled by AI. Each piece keeps its own file, so the set in the photo is the set you ship.

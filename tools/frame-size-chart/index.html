How to use the chart

If you sell prints, offer sizes that fit ready-made frames: buyers are far more likely to order a print they can frame the same day. Mat pairings vary by brand, so check the mat opening of the frame you recommend. For the ratio families behind these sizes, read our print ratio guide, and use the frame and mat calculator for custom sizes.

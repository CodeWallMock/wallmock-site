Etsy listing photo checker

Choose a batch of listing images. For each one you see its pixel size, ratio, file type and file size, and a preview with dashed boxes where centred 4:3 and square crops would fall. Everything runs in your browser; nothing is uploaded.

What the checks mean

Etsy's help article “Requirements and Best Practices for Images in Your Etsy Shop” lists the current recommended sizes, file types and limits; those figures change, so treat it as the source. Many sellers export images at least 2000 px on the shortest side, in 4:3 landscape or square, so buyers can zoom and search grids don't cut the artwork.

Keep the artwork inside both dashed boxes in your first photo: then it stays in view however the image is cropped in search results. For a plan for every photo slot, read our Etsy listing photos guide.

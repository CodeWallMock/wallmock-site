A wall art mockup API, in early access.

How will the WallMock API work?

  1. Upload the artwork

    Send each artwork file once. It is checked and kept only for processing, then deleted.

  2. Ask for images or a pack

    Choose rooms and products yourself, let the recommender pick rooms for the artwork's ratio, or request a listing pack with a preset.

  3. Collect the results

    A webhook tells your system when the job is done. Download each image from its signed link, with its exact-art check result.

How does the API handle security and privacy?

  • Deleted after processing. Artworks are deleted after processing.
  • No training. Your artworks are never used for training.
  • Signed result links. Finished images are fetched from signed links, not public URLs.
  • Exact-art check on every image. Each result records how closely the art matches your file.
  • Sandbox first. Build and test against watermarked images before you make clean ones.

Questions

Does WallMock have an API?

Not yet: the WallMock API is in development and not available yet; a private pilot is coming, and early access is by request at hello@wallmock.com. This page describes the current build, which may change before release.

Who is the WallMock API for?

Print companies, print-on-demand platforms, large art shops and listing tools that need room mockups for many artworks, made automatically from their own systems.

Is there a mockup API for print on demand that keeps the artwork exact?

That is what the WallMock API is built for. It runs the same renderer as the WallMock web app and places the artwork as supplied; it is never redrawn. Every room photo gets an exact-art check: the art in the image is compared with the uploaded file using SSIM, with mirrored and rotated copies of the art as controls. Close-ups are cut from a checked image. The API is in early access, not yet available.

Which products can the API show?

Floating canvas in 8 finishes, stretched canvas, framed prints with or without a mat, metal prints in Gloss, High gloss or Matte, and aluminium frames in black, gold or silver.

What is a listing pack?

One call returns a set of up to 10 listing photos for an artwork, organised by frame colour: hero, black, walnut, oak, gold, stretched, espresso, close-up, white and silver. You can turn slots on or off and reorder them, save partner presets, keep heroes unique across a batch, and choose Etsy, Shopify or generic image sizes.

Can a print company use its own frame names and photo order?

In the current build, yes: a saved partner preset keeps your own frame names, which slots are on and the order they come in, so every pack matches your catalogue's names and order. The products themselves are WallMock's frames and finishes.

How fast is the WallMock API?

In development tests, about 3 to 5 seconds per 4K image per worker, and a full listing pack in about 15 seconds. Speeds on production hardware may differ.

How much will the WallMock API cost?

Prices are not published yet. Pay per image, with volume plans. Early-access partners get pilot pricing. The WallMock Studio plan (coming soon) is planned to include 20% off API images.

Is there a sandbox or test mode?

In the current build, yes: a sandbox test mode returns watermarked images, so you can build and test an integration before making clean images. The API itself is in early access and not available yet.

What happens to the artwork we send?

Artworks are deleted after processing and never used for training. Finished images are delivered through signed result links, and webhooks tell your system when a job is done.

Is there a Shopify or Etsy integration?

Not generally yet. Send to Shopify is in beta testing (request access), and Send to Etsy is coming soon, pending Etsy's approval of our app. When Send to Shopify launches, Pro is planned to include 1 store and up to 25 products a month; the WallMock Studio plan (coming soon) adds 5 stores and Send to Etsy.

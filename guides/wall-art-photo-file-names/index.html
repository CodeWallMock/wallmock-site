A simple file-naming system for wall art listing photos

Published by WallMock · Updated 31 October 2026

Short answer: Use one short, repeatable pattern: artwork ID, product and finish, photo role, then revision. Keep source art, print files and listing images in separate folders. Give the sellable product or variant its own SKU in your shop system; a file name is for finding an export, not a substitute for the product record.

When a shop has several artworks, frame finishes and listing-photo roles, a download called “final-final-3.jpg” is easy to misplace. A small naming convention makes the right file easier to find and helps you catch a wrong finish before upload. Use it alongside your listing-photo plan to keep each export in its place.

Use five parts, in the same order

A useful filename answers: which artwork is this, what product does the image show, what job does this photo do, and which edit is current? For example:

blue-hour-sail_3x2_canvas-oak_hero_v02.jpg

PartExampleWhy it helps
Artwork IDblue-hour-sailFinds the design without repeating a long shop title
Ratio3x2Flags a shape that should not be stretched into a portrait slot
Product and finishcanvas-oakSeparates a canvas from a framed print or a different finish
Photo roleheroSeparates the main room image from a close-up or size guide
Revisionv02Shows which export replaced an earlier edit

Keep names short. Use lower-case letters, numbers, hyphens and underscores consistently. Avoid customer names, order details or personal information in filenames that may be shared with a printer, contractor or marketplace.

Separate source art, print files and listing exports

Give each kind of file its own place. Your untouched source artwork belongs in a source folder. Provider-ready production files belong in a print folder, with the provider’s required size and profile. Room mockups, actual sample photos, detail images and size guides belong in listing exports.

Do not overwrite the artwork master when you create a crop or product variant. Make the export name describe the change: blue-hour-sail_3x2_canvas-oak_hero_v02.jpg can sit beside blue-hour-sail_3x2_canvas-black_hero_v01.jpg. If the export changes, increment the revision and archive or remove the old listing file so you do not upload the wrong one by habit.

A tiny spreadsheet can hold the full record without making the filename unwieldy: artwork ID, product, finish, size, file role, revision, listing URL and upload status. The filename is the quick label; the sheet is the audit trail. See the bulk mockup workflow for organising a collection.

Keep a SKU separate from the photo name

An SKU identifies a product for your internal inventory and fulfilment. Etsy describes SKUs as a way to track inventory and find items in your shop or workspace (Etsy’s SKU guidance). Shopify says each product variant should have its own unique SKU for tracking and reporting (Shopify’s SKU guidance). Do not use a changing image filename as the SKU.

For example, an internal SKU might be SAIL-OAK-1624, while its listing image is blue-hour-sail_3x2_canvas-oak_hero_v02.jpg. The first identifies a product option in your shop; the second helps you locate a particular photo export.

Variants can change the product a photo needs to show. Shopify treats each combination of option values, such as size or colour, as a product variant (Shopify’s variant guide). Printify also supports assigning different artwork to specific variants for supported products (Printify’s variant instructions). Check your own product workflow, then make sure the image changes when the customer switches to a different option.

A complete example for one design

Suppose “Blue Hour Sail” is sold as canvas and as a matted framed print. Use a consistent set like this:

  • blue-hour-sail_3x2_canvas-oak_hero_v02.jpg — main room image for oak canvas;
  • blue-hour-sail_3x2_canvas-oak_detail-v01.jpg — canvas edge or close detail;
  • blue-hour-sail_3x2_framed-print-black-mat_hero_v01.jpg — different product and finish;
  • blue-hour-sail_3x2_sample-oak_front_v01.jpg — actual sample photo, if you have one;
  • blue-hour-sail_3x2_size-guide_v01.jpg — the labelled size comparison.

Before uploading, compare the filename with the actual image. A clear name cannot fix a wrong image; it can only make the mismatch easier to notice.

Do not turn filenames or alt text into keyword lists

A clear filename helps you organise a folder. Use it to find and check exports, while judging search performance separately. Use the marketplace’s title, tags, attributes and product details for what they ask for. Keep alt text for a concise description of what the image shows: Etsy explains that text alternatives help blind and low-vision shoppers understand listing images and should describe the picture (Etsy’s alt-text guidance). Shopify likewise recommends brief, descriptive alt text (Shopify’s media alt-text guidance).

For the sailboat hero, a useful alt description says that a sailboat painting hangs in a white floating frame above a sofa. It does not need a string of repeated phrases such as “wall art, wall decor, beach art, coastal print.” Add product or material details only when they are visible and accurate. The wall art photo alt-text guide has examples for each kind of image.

Questions

Do image filenames improve Etsy or Google ranking?

This naming system is for file management, not a ranking promise. Keep filenames clear and use each marketplace's listing fields for titles, tags, attributes and descriptions.

Should the filename be the product SKU?

No. Use a stable SKU to identify the sellable product or variant in your shop system. Use the filename to identify a photo export and its revision.

Should I put keywords in image alt text?

Describe what the image shows in concise, natural language. Do not repeat the listing title or add a keyword list; alt text is there to make the image understandable.

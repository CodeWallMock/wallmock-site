WallMock help

What files can I upload to WallMock?

Short answer: JPEG, PNG or WebP artwork files, one at a time or a whole collection. Each file keeps its own proportions, from square to 3:1 panoramas and 1:3 tall pieces, and is never stretched or cropped to fit a room.

Upload the same file you send to your print provider. For large prints, check that it has enough pixels with the print resolution checker, and see which sizes share its shape with the print size calculator.

Will my file be resized or redrawn?

WallMock places your file as it is: it is never redrawn, repainted or upscaled by AI.
